# ICSE Class 10 History - Personalized Study Repository

Welcome to the **ICSE Class 10 History** study repository. This project focuses on transforming traditional textbook content into engaging, pedagogical historical novels designed to ensure 100% syllabus coverage while maintaining high exam readiness.

## 📚 Features
- **Narrative Storytelling:** Complex historical events are broken down into character-driven chapters.
- **Socratic Dialogue:** Protagonists ask "Why?" and "What if?", leading the student to discover causes and consequences organically.
- **ICSE Board Vault:** Each chapter ends with actual board-style questions (MCQs, Short Answer, Structured) collected from past years and specimen papers.
